The user's ultimate running goal (after completing the injury-rehab ladder) is to **run 5K in under 35 minutes** (~7:00/km average), injury-free given MTSS / ankle reconstruction / knee history.

The evidence-based pace-development protocol is captured in `skill/running-pace-phase.md` and kicks in once Stage 9 (30min continuous) is consolidated. Key pillars: 80/20 polarized, strides → intervals → tempo order, +5% cadence for MTSS, calf/tibialis strength, 10% volume rule. Realistic timeline ~4–6 months from Stage 9.

**Why:** Established via a research request on 2026-08-25; the goal anchors all running progression decisions past the ladder.

**How to apply:** When the user reaches Stage 9, read `running-pace-phase.md` and follow it instead of the rehab ladder. See [[reference_dumbbell_steps]] and [[feedback_weight_increase_reset_reps]] for gym-side rules.
